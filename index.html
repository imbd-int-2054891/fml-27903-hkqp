Imobiliária Bandeirantes — uso interno
Uso interno da imobiliária. Importe o PDF que o locatário enviou (gerado pelo formulário online) para trazer automaticamente os dados de Locatários, Fiadores, Documentos, preferência de pagamento e animais. Depois é só completar Imóvel, Proprietário e Observações e gerar o PDF interno completo.

📤 Importar Dados do Formulário

📎 Arraste o formulário aqui ou clique para escolher (PDF)
Carregue aqui o PDF gerado pelo app do locatário para recuperar os dados enviados por ele. Funciona com o formulário completo (já marca os documentos que ele enviou) e também com o formulário básico, sem documentos (recupera só os dados — os documentos você marca aqui manualmente). Os campos de Imóvel, Proprietário e Observações não vêm de nenhum desses PDFs — preencha-os aqui depois de importar.
